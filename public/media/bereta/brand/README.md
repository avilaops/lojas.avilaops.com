# Símbolo Bereta Rodas

O símbolo digital isola o `B` usado na fachada e preserva as quatro barras de velocidade da marca.

## Arquivos

- `bereta-symbol.svg`: aplicação principal para fundos claros.
- `bereta-symbol-dark.svg`: aplicação para fundos escuros.
- `bereta-favicon.svg`: versão simplificada com fundo amarelo.
- `bereta-favicon-32.png`: favicon raster em 32 px.
- `bereta-favicon-192.png`: ícone para atalhos e dispositivos.
- `bereta-symbol-512.png`: símbolo principal em alta resolução.
- `bereta-brand-preview.svg`: prancha de apresentação das aplicações.

## Cores

- Amarelo Bereta: `#F0C014`.
- Grafite: `#17191D`.
- Branco quente: `#F7F6F2`.

O símbolo não deve ser inclinado, comprimido, contornado ou receber sombras. Em tamanhos menores que 48 px, use a versão `bereta-favicon.svg`.
